# Справочник по API

Справочник по C и C++ API генерируется из аннотаций в исходниках (`mdbx.h`,
`mdbx.h++`) инструментом Doxygen. Он доступен только на английском — перевод
справочника не планируется: аннотации API являются единственным источником
истины.

Точки входа:

- [Аннотированный индекс](api/annotated.md) — все классы и структуры
- [Классы](api/classes.md) · [Иерархия классов](api/hierarchy.md)
- [Пространства имён](api/namespaces.md)
- [Файлы](api/files.md) — C API (`mdbx.h`) со всеми функциями и макросами,
  а также C++ API (`mdbx.h++`)
- [Члены классов](api/class_members.md) · [Макросы](api/macros.md)

Вводное руководство — в [гайдах](index.md#документация-libmdbx); страница
[первых шагов](guides/first-steps.ru.md) показывает канонический поток
env → транзакция → DBI → get/put с готовыми примерами.
