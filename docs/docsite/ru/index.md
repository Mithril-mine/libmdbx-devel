# Документация libmdbx

**libmdbx** — встраиваемая транзакционная база данных «ключ-значение»:
компактная, очень быстрая (memory-mapped, B+tree, O(log N)), ACID, устойчивая
к сбоям по умолчанию, без WAL и без серверного процесса — безопасная для
конкурентного доступа из многих процессов.

Выберите раздел:

- **[Обзор](guides/overview.ru.md)** — что такое libmdbx, характеристики,
  сравнение с альтернативами и когда его выбирать (плюс честный список
  [ограничений и подводных камней](guides/restrictions.ru.md)).
- **[Начало работы](guides/install-build.ru.md)** — формы поставки, как
  собрать, [первые шаги](guides/first-steps.ru.md) с API и
  [режимы durability](guides/durability-modes.ru.md).
- **[Учебник](textbook/ru/README.md)** — практическое руководство в шести
  томах, от первых шагов до экспертных тем и биндингов.
- **[Погружение](engineering/architecture.ru.md)** — архитектура, внутренние
  механизмы и усовершенствования libmdbx относительно LMDB.
- **[Справочник](api.ru.md)** — справочник по C/C++ API, утилиты командной
  строки и журнал изменений.
