> через PR в этот файл, см. преамбулу контракта). Ниже — дельта относительно
> редакции от 2026-10-10; применяется после того, как раздел `/docs/**`
> начнёт раздаваться из нового генератора (`make docsite`).

Предложенные правки отмечены **[+]** (новое), **[~]** (взамен существующего
текста). Всё, что не отмечено, остаётся без изменений.

## §1. Архитектура — **[+]** в конце раздела

```
- Генератор документации детерминирован (`make docsite`): hreflang-данные
  (§3.1, §4.3) и связки переводов (§4.1) выводятся из одного источника
  (карты соответствия страниц-близнецов), тройная согласованность §6.7
  проверяется автоматически при каждой сборке.
```

*(Фактически дублирует §5-абзац про регенерацию — можно ограничиться §5.)*

## §4.1. TechArticle — **[+]** в «Правила»

```
- Страницы справочника API (`/docs/en/reference/api/**`) и журнал изменений
  (`/docs/en/reference/changelog.html`) существуют только в EN-локализации:
  перевода справочника нет (вопрос хранения/синхронизации перевода между
  локализациями пока не решён). Такие страницы:
  - не несут полей `workTranslation`/`translationOfWork`;
  - имеют `inLanguage: "en"`;
  - в sitemap несут hreflang-аннотации `en` и `x-default` (без `ru`);
  - исключаются из чек-листа §6.6 (пара RU↔EN отсутствует намеренно).
  RU-лендинг справочника (`/docs/ru/reference/index.html`) ссылается на
  EN-страницы с явным примечанием об отсутствии перевода.
```

## §4.2. BreadcrumbList — **[~]**

Вместо примера с выделенным URL раздела-хаба:

```
URL уровня «Раздел» — каноническая страница-вход раздела (не отдельная
страница-хаб): Обзор → /docs/<lang>/overview/index.html, Начало работы →
…/getting-started/install-build.html, Учебник → …/textbook/index.html,
Погружение → …/deep-dive/architecture.html, Справочник →
…/reference/index.html. Для страницы-входа уровня «Раздел» она же является
и последним уровнем (два элемента списка).
```

## §4.3. hreflang — **[~]**

Дополнить после «Данные обязаны совпадать…»:

```
Страницы, существующие только в EN-локализации (см. §4.1), несут только
`hreflang="en"` и `x-default`; для них `hreflang="ru"` не издаётся, чтобы
не ссылаться на несуществующие 200-URL (см. §6.1).
```

## §5. Языки и URL — **[+]**

```
- Корневая страница-селектор `/docs/index.html` (единственная цель
  gateway-редиректа `docs/`) выполняет автоматический переход на
  локализованную страницу по первому языку из `navigator.languages`
  (`ru*` → `/docs/ru/index.html`, `en*` → `/docs/en/index.html`, иначе
  остаётся селектором). Ручной выбор языка сохраняется в `localStorage`
  (ключ `docs:lang`) и перекрывает предпочтения браузера; при наличии query
  string или hash авто-переход не выполняется. Селектор — языково-нейтральная
  страница: без JSON-LD (§4) и без hreflang-аннотаций (§3.1).
```

## §6. Чек-лист — **[~]** пункт 6

```
6. **Пары RU↔EN:** каждая страница `/docs/ru/…` имеет пару `/docs/en/…` и
   наоборот (исключения — страницы с общим URL, например селектор, и
   EN-only страницы справочника API и журнала изменений, см. §4.1).
```

## Сопроводительные факты (для ревью PR)

- Тройная согласованность (§6.7) обеспечивается генерацией: карта
  страниц-близнецов живёт в `docs/docsite/hooks/docsite_hooks.py`, из неё
  выводятся `<head>`-ссылки, sitemap-аннотации и поля перевода ld+json;
  соответствие проверяет `docs/docsite/verify_contract.py`, встроенный в
  `make docsite` (падает при любом рассогласовании).
- Канонические URL: `https://libmdbx.dqdkfa.ru/docs/{ru,en}/<путь>.html`,
  селектор — `https://libmdbx.dqdkfa.ru/docs/index.html`.
- `Content-Type: application/xml` для `/docs/sitemap.xml` — на стороне
  hosting/gateway (в бакете файл лежит как `sitemap.xml`).
- Справочник API генерируется из аннотаций `mdbx.h`/`mdbx.h++` (Doxygen),
  поэтому он English-only по построению; RU-дерево ссылок на него не имеет.
