# Глоссарий (компактный)

> Часть индекса [документации разработчика](README.md).
> Короткие определения терминов, встречающихся в обсуждениях libmdbx и в
> переформулировках записей базы знаний. Полный функциональный разбор —
> в [`functional-architecture.md`](functional-architecture.md) (раздел «Глоссарий»).

| Термин | Определение |
| --- | --- |
| **B+tree** | Сбалансированное дерево: данные в листьях, внутренние узлы — разделители; O(log N) поиск. |
| **MVCC** | Мультиверсионность: несколько снапшотов данных одновременно; читатели не блокируют писателя. |
| **CoW (copy-on-write)** | Изменяемая страница не модифицируется на месте — создаётся её новая версия; старые версии видны читателям. |
| **MMap** | Файл БД отображён в память; данные доступны как массив байт, чтение без копирования. |
| **writemap / `MDBX_WRITEMAP`** | Режим прямой записи грязных страниц в mmap-область (вместо `pwrite`). |
| **overflow / large page** | Контигуальная цепочка страниц для значений, не помещающихся в лист. |
| **subpage / суб-страница** | Компактное хранилище мультизначений внутри листовой страницы. |
| **GC / GC-дерево (freelist)** | Учёт свободных страниц: записи ключами по txnid внутри B+tree самого файла. |
| **Детент (detent)** | Старейший активный читательский снапшот; водораздел переиспользования страниц. |
| **«Застрявшие читатели» / straggler** | Долгие read-транзакции, удерживающие снапшот и блокирующие переработку страниц. |
| **RLT (reader lock table)** | Таблица читателей в файле блокировок (LCK). |
| **HSR (Handle-Slow-Readers)** | Колбэк разрешения конфликта с долгими читателями при исчерпании пространства. |
| **Steady / weak мета** | Устойчивый (данные на диске) / слабый (не гарантирован) снапшот. |
| **steady-point / steady-коммит** | Устойчивая точка; до неё гарантировано восстановление даже в `MDBX_SAFE_NOSYNC`. |
| **Troika** | Три мета-страницы с двухфазной фиксацией (216 комбинаций конечного автомата). |
| **Sync modes** | Режимы долговечности: durable / nometasync / safe_nosync / utterly_nosync / writemap. |
| **presync** | Подготовительный сброс данных перед фиксацией меты (`MDBX_opt_presync_threshold`, `mdbx_env_sync_ex(force=false)`). |
| **WAF** | Write Amplification Factor — кратность записи на диск относительно объёма пользовательских данных. |
| **DPL / грязный список** | Страницы, изменённые в памяти и ждущие записи при коммите. |
| **Спилл (spill)** | Заблаговременная выгрузка грязных страниц на диск при переполнении лимита. |
| **Loose-страницы** | Небольшой кэш освобождённых страниц для быстрого переиспользования в текущей транзакции. |
| **Refund** | Возврат освобождённых хвостовых страниц в неразмеченное пространство. |
| **Implicit shrink** | Автоматическое усечение файла при накоплении свободного хвоста (бесплатная компактификация). |
| **BigFoot** | Цепочка GC-записей на последовательных txnid для очень больших освобождений. |
| **FIFO/LIFO (reclaiming)** | Политика выбора GC-записей по ключу (txnid): по умолчанию FIFO (старые освобождения раньше), `MDBX_LIFORECLAIM` — LIFO (свежие раньше). Определяет порядок записей, а не номера страниц (номера сортируются независимо, `MDBX_PNL_ASCENDING`). |
| **Dupsort-таблица** | Таблица-мультикарта: один ключ → упорядоченное множество значений. |
| **Bunch delete** | Массовое удаление «гроздьями»: вырезание целых страниц/ветвей. |
| **Range estimation** | Эвристическая оценка числа элементов в диапазоне по общим страницам стеков курсоров. |
| **Парковка / вытеснение** | Освобождение читателем слота с сохранением хендла (`park`); принудительное «выселение» снапшота (`ousted`). |
| **NOSTICKYTHREADS** | Режим передачи транзакции между потоками (без «прилипания» к потоку-создателю). |
| **boot-id** | Идентификатор загрузки ОС, учитываемый при откате слабых мета-страниц (важно в LXC). |
