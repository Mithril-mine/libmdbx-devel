# Human documentation

Человеко-ориентированная проектная документация libmdbx. Публичная часть
(источник единого сайта `make docsite`) — в `docs/ru/` (канонический оригинал)
и `docs/en/` (перевод); инженерные доки для агентов (архитектура, сборка,
структура, C++ API, тесты, техдолг и т.п.) — в `docs/engineering/`, точка
входа: [`docs/engineering/README.md`](engineering/README.md).

Учебник по libmdbx (шесть томов + каркас) — в [`docs/ru/textbook/`](ru/textbook/index.md)
(перевод — [`docs/en/textbook/`](en/textbook/index.md)); работающие примеры к
нему — в [`examples/`](../examples/README.md).

Агент-ориентированный слой знаний (карта, экспорт записей памяти) — в
[`../skynet/knowledge-map.md`](../skynet/knowledge-map.md).

Кандидаты на избирательное включение в амальгамированную поставку (`make dist`)
отбираются отсюда отдельной задачей.
