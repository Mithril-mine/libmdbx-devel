# Human documentation

Человеко-ориентированная проектная документация libmdbx. В `docs/engineering/`
лежат инженерные доки (архитектура, сборка, структура, C++ API, тесты, техдолг
и т.п.) — точка входа: [`docs/engineering/README.md`](engineering/README.md).

Агент-ориентированный слой знаний (карта, экспорт записей памяти) — в
[`../skynet/knowledge-map.md`](../skynet/knowledge-map.md).

Кандидаты на избирательное включение в амальгамированную поставку (`make dist`)
отбираются отсюда отдельной задачей.
