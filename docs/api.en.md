# API reference

The C and C++ API reference is generated from the source annotations
(`mdbx.h`, `mdbx.h++`) by Doxygen. It is available in English only —
translations of the reference are not planned: the API annotations are the
single source of truth.

Entry points:

- [Annotated index](api/annotated.md) — all classes and structures
- [Classes](api/classes.md) · [Class hierarchy](api/hierarchy.md)
- [Namespaces](api/namespaces.md)
- [Files](api/files.md) — includes the C API (`mdbx.h`) with all functions
  and macros, and the C++ API (`mdbx.h++`)
- [Class members](api/class_members.md) · [Macros](api/macros.md)

Getting-started guidance lives in the [guides](index.md#libmdbx-documentation);
the [first steps](guides/first-steps.en.md) page shows the canonical
env → transaction → DBI → get/put flow with runnable examples.
