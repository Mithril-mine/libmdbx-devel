# external-consult — консультации с внешним AI-агентом (Level 2, для всех ролей)

> Иерархия SKILLS: общий слой. Подробности — `../../alice-consult-codex.md`
> (правила, маршрутизация, безопасность) и `.skynet/tools/alice-consult.py`.

## Когда использовать

Внешняя консультация (Алиса / модели Yandex AI Studio) уместна как **второе
мнение / дополнительный взгляд**:
- креативная дивергенция и генерация идей (брейншторм);
- анализ/разбор сложной задачи, инцидента;
- классификация/извлечение (структурированный JSON);
- второй взгляд на ревью кода, проектирование;
- поиск актуальной информации.

НЕ использовать как замену исполнению, верификации (Gemba) или решениям.

## Правила (кратко)

1. **Санитайзинг обязателен**: внешний сервис — только обобщённые формулировки,
   без ключей/кода/логов/внутренних метрик/ПДн (см. issues-pr-codex §0).
2. Вопрос → обдуманный ответ, результат проверять (модель может ошибаться).
3. Экономия токенов: маршрутизация по типу, reasoning по необходимости.
4. Итог консультации — в отчёте (что спросили, что взяли в работу).

## Использование

```
python3 /sourcecraft/workspace/.skynet/tools/alice-consult.py --ask "<вопрос>" [--route analysis|code|brainstorm|...]
```

Полная справка: `--help`; правила и безопасность: `../../alice-consult-codex.md`.
